# Plain Craft Launcher – Ray Custom (PCL-RC)

> PCL-RC 是基于 Plain Craft Launcher 2（PCL2）制作的**非官方**个人修改版本，与原作者及 PCL-CE 社区无官方关联。

本项目由 Ray20123315 维护，主要提供 Modrinth 社区资源、Minecraft 启动管理、可选的注册表隔离，以及根据不同构建配置选择启用的下载地区检查。

- **公开版本**：不预置 Microsoft Client ID，启用地区检查。
- **私人测试版本**：通过独立的私人仓库提供三种 Microsoft Client ID / 地区检查组合。
- CurseForge 网络功能目前暂停，保留相关源代码与文件；未经授权不会公开发行 API Key。
- 地区检查通过获得许可的 Windows 设备位置及备用的地区判定实现，不保证 GPS、反 VPN 或各地法规合规。
- Minecraft 正版登录功能仍需实际验证 Microsoft 应用与 Minecraft Services 的许可情况。
